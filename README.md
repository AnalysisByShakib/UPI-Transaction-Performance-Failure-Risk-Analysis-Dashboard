# UPI Transaction Analytics Dashboard - Performance, Failure & Risk Analysis
An interactive Microsoft Excel dashboard designed to analyze UPI transaction performance, transaction failures, and suspected fraud/risk patterns, helping identify key trends and generate actionable insights for data-driven decision-making.

## Business Problem
UPI platforms want to understand transaction across different apps, state, customer segment, payment mode, suspected fraud/risk patterns and merchant categories.
This project focuses on answering questions such as:
Dashboard 1 
- How much transaction value is being generated ?
- How ssuccessful are transaction ?
- What percentage of transactions are suspected to be fraudulent ?
- Which UPI payment are being used most ? 
- Which state contributes the most transaction value ?
- When is transaction activity highest ?
- Which customer age group are generate the most transaction value ?
- Which UPI payment mode is being used most ?
- What is the success rate & total cashback ?
Dashboard 2 
- How many transactions failed ?
- What are the major reasons for transaction failures ?
- What is the failure rate ?
- Which UPI app has the higher average risk score ?
- When are the failures happening ?
- Which UPI app have more failure rate ?

## Project Objective
The objective of this project is to build an interactive Excel dashboard to analyze:
- UPI transaction performance ?
- Customer payment behavior 
- Suspected fraud/risk
- Success and failure rates
- Transaction trends
- UPI app performance
- Failure reasons

The dashboard is intended to help business improve transaction success ,understand customer preferences, optimize payment operations and strengthen fraud & risk monitoring.
